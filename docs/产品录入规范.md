# 苏州德力 - 产品录入规范

## 一、产品信息录入规范

### 1.1 数据文件位置
- **主数据文件**: `products.json`
- **图片目录**: `image/`

### 1.2 JSON 格式规范

每个产品必须包含以下字段：

```json
{
  "产品名称": "产品名",
  "规格": "艺术照/尺寸 组合照/尺寸 摆台/尺寸 相册名/尺寸",
  "产品介绍": "产品介绍文字或 null"
}
```

### 1.3 字段说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 产品名称 | string | 是 | 产品中文名称，与图片文件名一致（去掉空格） |
| 规格 | string/null | 否 | 规格参数，格式见下方 |
| 产品介绍 | string/null | 否 | 产品介绍文案，无则填 null |

### 1.4 规格参数格式

**标准格式**: 类别/内容 类别/内容 ...

```
艺术照/110x60cm-1 组合照/35x50cm-2/45x50cm-1 摆台/15x20cm-2 卡蔓黑/10x10寸(50x25.4cm)/14x14寸(70x35.5cm)
```

**规则**:
- 类别名称：艺术照、组合照、摆台、相册名（如卡蔓黑、格拉芙等）
- 类别与内容之间用 `/` 分隔
- 同一类别多个尺寸用 `/` 分隔
- 不同类别之间用**空格**分隔
- 尺寸格式：`宽x高cm-数量` 或 `宽x高寸(括号说明)`

### 1.5 图片命名规范

- 图片文件名 = 产品名称（去除空格）
- 格式：`产品名称.jpg`
- 示例：
  - 产品名称: `黛莲娜` → 图片名: `黛莲娜.jpg`
  - 产品名称: `克莱茵S2` → 图片名: `克莱茵S2.jpg`
  - 产品名称: `夕 瑶` → 图片名: `夕瑶.jpg`（去掉空格）

### 1.6 拼音映射

在 `main.js` 的 `convertToPinyin()` 函数中添加新产品的拼音映射：

## 二、添加新产品流程

### 2.1 添加单个产品

1. **准备图片**: 将产品效果图放入 `image/` 目录，命名为 `产品名.jpg`
2. **编辑 products.json**: 在数组末尾添加新产品数据
3. **添加拼音映射**: 在 `main.js` 的 `convertToPinyin()` 中添加新产品名和拼音
4. **刷新页面**: 清除浏览器缓存后刷新

### 2.2 添加多个产品

1. **批量准备图片**: 所有图片放入 `image/` 目录
2. **编辑 products.json**: 批量添加产品数据
3. **批量添加拼音映射**: 在 `main.js` 中一次性添加所有新产品的拼音
4. **刷新页面**: 清除浏览器缓存后刷新

## 三、修改产品信息

### 3.1 修改产品规格
直接编辑 `products.json` 中对应产品的 `规格` 字段

### 3.2 修改产品介绍
直接编辑 `products.json` 中对应产品的 `产品介绍` 字段

### 3.3 更换产品图片
1. 删除 `image/` 目录下的旧图片
2. 放入新图片，保持文件名一致

## 四、示例

### 4.1 添加新产品 "星辰"

**步骤 1**: 准备图片 `image/星辰.jpg`

**步骤 2**: 在 `products.json` 中添加：
```json
{
  "产品名称": "星辰",
  "规格": "艺术照/110x60cm-1 组合照/50x50cm-3 摆台/20x25cm-2 星辰/10x10寸(50x25.4cm)/14x14寸(70x35.5cm)",
  "产品介绍": "星辰系列，以璀璨星光为灵感..."
}
```

**步骤 3**: 在 `main.js` 中添加拼音映射：
```javascript
'星辰': 'xingchen',
```

**步骤 4**: 刷新页面查看效果
