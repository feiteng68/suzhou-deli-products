# 苏州德力 - 完整工作流程

## 一、项目概述

**项目名称**: 苏州德力微信公众号产品展示页面
**项目类型**: H5 移动端产品画廊
**技术栈**: HTML + CSS + JavaScript（无框架）
**部署方式**: 静态文件托管（微信公众号 H5 页面）

## 二、文件结构

```
微信公众号/
├── index.html              # HTML 页面结构
├── style.css               # CSS 样式文件
├── main.js                 # JavaScript 交互逻辑
├── products.json           # 产品数据文件
├── products_data.json      # 原始 Excel 导出数据（备份）
── image/                  # 产品图片目录
│   └── *.jpg               # 产品效果图
├── docs/                   # 文档目录
│   ├── 产品录入规范.md
│   ├── 页面样式标准.md
│   ├── 工作流程.md
│   └── SKILL.md
├── read_excel.py           # Excel 数据提取脚本
├── generate_pinyin.py      # 拼音生成脚本
└── 产品图片规格.xlsx        # 原始 Excel 数据
```

## 三、添加新产品完整流程

### 步骤 1: 准备产品图片
1. 获取产品效果图（JPG 格式）
2. 将图片放入 `image/` 目录
3. **命名规则**: 产品名称去掉空格 + `.jpg`
   - 例: `黛莲娜` → `黛莲娜.jpg`
   - 例: `克莱茵S2` → `克莱茵S2.jpg`
   - 例: `夕 瑶` → `夕瑶.jpg`

### 步骤 2: 编辑产品数据
1. 打开 `products.json`
2. 在数组末尾 `]` 之前添加新产品数据：
```json
{
  "产品名称": "新产品名",
  "规格": "艺术照/110x60cm-1 组合照/50x50cm-3 摆台/20x25cm-2 相册名/10x10寸(50x25.4cm)/14x14寸(70x35.5cm)",
  "产品介绍": "产品介绍文字，无则填 null"
}
```

### 步骤 3: 添加拼音映射
1. 打开 `main.js`
2. 找到 `convertToPinyin()` 函数中的 `pinyinMap` 对象
3. 添加新产品的拼音映射（按字母顺序插入）：
```javascript
'新产品名': 'xinchangpinming',
```

### 步骤 4: 验证
1. 保存所有修改的文件
2. 清除浏览器缓存
3. 刷新页面 `http://localhost:8080/index.html`
4. 检查新产品是否正确显示

## 四、修改产品信息流程

### 4.1 修改规格参数
```json
// products.json 中找到对应产品，修改"规格"字段
{
  "产品名称": "黛莲娜",
  "规格": "艺术照/110x60cm-1 组合照/35x50cm-2 摆台/15x20cm-2",  // 修改此处
  "产品介绍": null
}
```

### 4.2 修改产品介绍
```json
// products.json 中找到对应产品，修改"产品介绍"字段
{
  "产品名称": "良缘",
  "规格": "...",
  "产品介绍": "新的产品介绍文字..."  // 修改此处
}
```

### 4.3 更换产品图片
1. 删除 `image/` 目录下旧图片
2. 放入新图片，**文件名必须与产品名称一致**（去掉空格）
3. 刷新页面

## 六、部署流程

### 6.1 本地测试
```bash
# 在项目目录启动本地服务器
python -m http.server 8080
# 访问 http://localhost:8080/index.html
```

### 6.2 微信公众号部署
1. 将整个项目文件夹上传到服务器
2. 在微信公众号后台配置 H5 页面链接
3. 确保图片路径正确（相对路径 `./image/`）

### 6.3 注意事项
- 所有文件使用 UTF-8 编码
- 图片文件名不要包含特殊字符
- 确保 `products.json` 格式正确（JSON 语法）
- 拼音映射要覆盖所有产品名称

## 七、常见问题

### Q1: 产品图片不显示？
- 检查图片文件名是否与产品名称一致（去掉空格）
- 检查图片是否在 `image/` 目录下
- 检查浏览器控制台是否有 404 错误

### Q2: 规格参数不显示？
- 检查 `products.json` 中 `规格` 字段格式是否正确
- 规格格式：`类别/内容 类别/内容`（用空格分隔）

### Q3: 搜索功能不工作？
- 检查 `main.js` 中是否添加了该产品的拼音映射
- 检查浏览器控制台是否有 JavaScript 错误

### Q4: 页面样式异常？
- 清除浏览器缓存
- 检查 `style.css` 是否被正确加载
- 检查浏览器是否支持 CSS 变量
