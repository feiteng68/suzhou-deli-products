# 苏州德力 - 快速入门指南

## 一、添加新产品（3 步完成）

### 第 1 步：放图片
将产品效果图放入 `image/` 文件夹，命名规则：
```
产品名称去掉空格.jpg
```
示例：`黛莲娜.jpg`、`克莱茵S2.jpg`

### 第 2 步：改数据
打开 `products.json`，在 `]` 前面添加：
```json
{
  "产品名称": "新产品名",
  "规格": "艺术照/110x60cm-1 组合照/50x50cm-3 摆台/20x25cm-2 相册名/10x10寸(50x25.4cm)/14x14寸(70x35.5cm)",
  "产品介绍": "产品介绍文字，没有就写 null"
}
```

### 第 3 步：加拼音
打开 `main.js`，找到 `convertToPinyin` 函数，添加：
```javascript
'新产品名': 'xinchangpinming',
```

### 完成！
刷新页面 `http://localhost:8080/index.html` 查看效果

## 二、修改产品规格

打开 `products.json`，找到对应产品，修改 `规格` 字段：

```json
// 修改前
"规格": "艺术照/110x60cm-1 组合照/35x50cm-2"

// 修改后
"规格": "艺术照/110x60cm-1 组合照/35x50cm-2/45x50cm-1 摆台/15x20cm-2"
```

---

## 三、修改产品介绍

打开 `products.json`，找到对应产品，修改 `产品介绍` 字段：

```json
// 修改前
"产品介绍": null

// 修改后
"产品介绍": "产品介绍文字内容..."
```

---

## 四、更换产品图片

1. 删除 `image/` 下的旧图片
2. 放入新图片，**文件名必须和原来一样**
3. 刷新页面

---

## 五、规格参数格式

```
艺术照/110x60cm-1 组合照/35x50cm-2/45x50cm-1 摆台/15x20cm-2 相册名/10x10寸(50x25.4cm)/14x14寸(70x35.5cm)
```

**规则**：
- 类别和内容用 `/` 分隔
- 多个尺寸用 `/` 分隔
- 不同类别用**空格**分隔
