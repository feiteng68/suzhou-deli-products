# 苏州德力 - 页面样式标准文档

## 一、设计系统

### 1.1 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#F5F5F7` | 页面整体背景色（极浅灰） |
| 卡片背景 | `#FFFFFF` | 产品卡片背景 |
| 规格/介绍背景 | `#FAFAFA` | 规格参数和产品介绍区域背景 |
| 主文字色 | `#1D1D1F` | 标题、产品名等主要文字 |
| 次要文字色 | `#6E6E73` | 产品介绍文字 |
| 标签文字色 | `#8E8E93` | 规格标签、字母导航默认色 |
| 分割线 | `#F0F0F0` | 规格项之间的分割线 |
| 边框色 | `#E8E8ED` | 卡片边框 |
| 搜索框边框 | `#E2E2E2` | 搜索框默认边框 |
| 搜索框焦点 | `#8E8E93` | 搜索框激活边框 |
| 占位文字 | `#C0C0C0` | 搜索框 placeholder |
| 装饰线 | `#C0C0C0` | 产品名下方装饰线 |
| 底部文字 | `#8E8E93` | Footer 文字 |

| 元素 | 动画效果 | 时长 | 缓动函数 |

| 字母导航悬停 | 底部横线出现 | 0.2s | default |
| 卡片入场 | fadeIn (opacity + translateY) | 0.4s | ease-in |
| 返回顶部 | opacity 变化 | 0.3s | default |

─────────────────────────────────┤

├─────────────────────────────────┤
│     Letter Navigation (24px)    │
│     字母筛选按钮                │
├─────────────────────────────────┤
│      Product Grid               │
│    ┌─────┐  ┌─────┐            │
│    │卡片1 │  │卡片2 │           │
│    └─────┘  └─────┘            │
│    ┌─────┐  ┌─────┐            │
│    │卡片3 │  │卡片4 │           │
│    └─────┘  └─────┘            │

### 2.2 响应式断点

| 断点 | 布局 | 说明 |
|------|------|------|
| > 600px | 2列网格 | 桌面/平板横屏 |
| ≤ 600px | 1列网格 | 手机/平板竖屏 |

### 2.3 最大宽度

- 全局容器: `max-width: 1000px`
- 产品网格: `max-width: 1000px`

## 三、组件规范

### 3.1 Header 组件
- 背景: `#F5F5F7`（透明，与页面背景一致）
- 品牌标题: 居中，32px Bold，字间距 12px
- 副标题: 居中，13px Regular，#8E8E93
- 无边框、无阴影

### 3.2 搜索框组件
- 容器: 透明背景，无阴影
- 输入框: 白色背景，1px #E2E2E2 边框，12px 圆角
- 内边距: 16px 48px 16px 52px
- 搜索图标: 左侧 20px，18px 细线条 SVG
- 清除按钮: 右侧 16px，#8E8E93
- Placeholder: #C0C0C0，300 字重
- 焦点状态: 边框变为 #8E8E93

### 3.3 字母导航组件
- 容器: 白色背景，16px 圆角，1px #E8E8ED 边框
- 字母项: 透明背景，无圆角，无边框
- 默认: #8E8E93，400 字重
- 激活: #1D1D1F，600 字重，底部 2px 黑色横线
- 悬停: 字母变 #1D1D1F，底部横线出现

### 3.4 产品卡片组件
- 卡片: 白色背景，16px 圆角，1px #E8E8ED 边框，无阴影
- 图片区域: 白色背景，100% 宽高比，图片居中 contain
- 产品名: 20px Medium，居中，底部 1px #C0C0C0 装饰线（24px 宽）
- 规格区域: #FAFAFA 背景，12px 圆角，无阴影
- 规格项: 标签 #8E8E93（12px），数值 #1D1D1F（13px）
- 介绍区域: #FAFAFA 背景，12px 圆角，无阴影
- 介绍文字: #6E6E73，13px，行高 1.8

### 3.5 Footer 组件
- 固定底部，白色背景
- 上边框: 1px #E8E8ED（无阴影）
- 文字: #8E8E93，12px，居中
- 内边距: 16px
